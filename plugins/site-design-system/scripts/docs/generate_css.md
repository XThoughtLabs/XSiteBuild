# generate_css.py

Design-first sites: the public `tokens.css` and the matching `trace-map.yaml` from `DESIGN.md` (plan 0.4 B.3.3).

- **Inputs:** `--site <folder> [--tokens PATH] [--write]` (without `--write` it prints). It reads `DESIGN.md`, `site.yaml`, `policy.yaml` (its scheme mode and pairs) and the existing `trace-map.yaml` (clamp expressions): write the policy before the first generation.
- **Names:** `--color-<t>`, `--radius-<t>`, `--space-<t>`, `--type-<level>-family|size|weight|line|tracking`, `--comp-<component>-<field>`; references become `var()` of the referenced token; fluid sizes take their `clamp_expr` from the existing trace map; `scheme.mode: both` adds a `prefers-color-scheme: dark` block from the pairs. The trace map is rewritten. Component fields bind to their `--comp-…` variables until `site.yaml` names component stylesheets (plan 0.4 B.3.3 step 5); from then on every field those stylesheets define for the component's selector binds to that selector and property (`backgroundColor` to `background-color` or `background`, `textColor` to `color`, `rounded` to `border-radius`, `padding`, `height`, `width`; typography when they declare a font property there), and a field they do not define keeps its variable (`size` always does). The component's selector is the one the existing trace map names for it (any field's `sel`), else `.<component>`.
- **Deterministic:** the same `DESIGN.md` gives the same bytes, with LF line ends on every platform; the first line names the generator version and the source's SHA-256. `check_design.py` fails a `tokens.css` that differs from a fresh render.
- **Destinations:** the tokens file never inside the site design folder, and inside the deploy root when `site.yaml` names one (else ERROR 2). Both files are written to a new file renamed into place; an existing name that is a link, a junction, a hard link or not a regular file is refused (ERROR 2), and `trace-map.yaml` is read through the same validated name.
- **Outcomes:** 0 printed or written, 2 an input, a reference the generator cannot project, or a destination unusable (named), 4 unexpected.
