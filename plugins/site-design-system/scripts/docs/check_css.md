# check_css.py

The static role check of a page's own CSS (plan 0.4 B.7.4, after Mozilla's `use-design-tokens` lint rule).

- **Bundle mode:** `--site <folder> --bundle <folder> --page <relative path> [--json FILE] [--no-git] [--receipt-sha256 HEX]`. Receipt first (missing, invalid, stale or, where a repository is reachable, not equal to its committed blob: INCOMPLETE, nothing checked; with no Git repository approval counts only with `--receipt-sha256`, the SHA-256 of the issued `ready.json`). Sources: the page and its same-bundle frame documents (`iframe src`, `srcdoc`, at most 50 documents), each document with its own variable map (a variable defined in a frame or `srcdoc` never resolves a declaration of another document; a sheet linked by several documents applies to each): linked local stylesheets, `<style>` elements, `style=""` attributes (the tag is the selector, so `<code style>` is a code role), SVG `fill`, `stroke` and `stop-color` attributes; nothing inside an inert `<template>`. The first of duplicate attributes counts, as in browsers. A linked sheet whose SHA-256 equals a CSS file of the receipt is the approved site CSS: listed (INFO), not role-checked.
- **Guard:** every bundle file read passes the guard shared with `check_page.py` (`bundlelib.py`): a VCS, `.env*`, `*.pem` or `*.key` name in any path component, a profile file's name in any case, bytes equal to a file of the site design folder, links, junctions, reparse points, hard links and non-regular files are refused (ERROR 2) and never parsed or quoted. References are percent-decoded as the browser and the loopback server decode them; a decoded path holding a control character (U+0000–U+001F), or a component the portable grammar refuses (a trailing dot or space, `:`, a Windows-reserved character, a short 8.3 alias, a device name; see `check_page.md`), is outside the bundle (A10 failure), never read or quoted. The bundle root is opened once; a link at the root is refused.
- **Rule:** each role-bearing declaration (`color`, `background-color`, `border-*-color`, `outline-color`, `box-shadow`, `fill`, `stroke`, `stop-color`, `font-family`, the family of `font` (written out, or exactly one approved font-stack variable); shorthands `border*`, `outline`, `background` expanded for their colour parts; every gradient stop, whatever its spelling) takes a contract variable of an allowed token for its role and scheme, a literal token's exact value, an extra in its roles and alpha, a derived variable in its roles, a font-stack variable or approved face, or a keyword (`currentColor`, `transparent`, CSS-wide). `fill`/`stroke: url(#id)` names a paint server whose stops are judged where declared. Every definition of a page variable is checked, by one resolver with one budget in every path that resolves one (shorthand colour parts, contract restatements, `color-mix()` operands, `font-family`, fallbacks): at most 64 definitions expanded per declaration, more give one INCOMPLETE ("too many variable definitions to check"), never a silent cut; `var()` fallbacks are checked at every level, inside `color-mix()` operands too, and must not be hard-coded; a variable cycle fails; contract variables may be restated only with their own value and every other certified variable (the trace map's, the font stacks, the derived ones) only with its approved value; a font-stack variable is accepted only when certified (the first family of its approved value an approved face, every other family an approved face, a generic family or a family listed in `fonts.fallback_families`); a literal `font-family` stack is accepted on the same rule: its first family an approved face, every other family an approved face, a generic family or a family listed in `fonts.fallback_families` (the CEO's decisions of 2026-11-11 and 2026-11-12: one rule for every stack, a variable or a literal one; a stack of generic families alone fails in both); `color-mix()` (in srgb) is resolved with its fractional channels and alpha kept until the exact comparison with the allowed colours (no rounding, no tolerance: authored values) and `light-dark()` is resolved; named colours are raw values.
- **Report mode:** `--site <folder> --report <css> [...]`: hard-coded values in role-bearing properties by file and line, read through the same parts as the rule (colour parts, gradient stops, family stacks; style rules and `@keyframes`); unsupported at-rules are named. Informational: exit 0 unless unreadable, and no checker outcome word is printed (the summary says "report only, exit 0"); the JSON's `outcome` is `REPORT`. A truncated report keeps its total line and says "report truncated: N of M items printed".
- **Outputs:** `--json` never inside the site design folder (ERROR 2); written before the summary is printed, to a new file renamed into place (a destination that is a link, a junction, a hard link or not a regular file is refused, ERROR 2); at most 5,000 report items, the truncation item included (bundle mode: failures first, INCOMPLETE); the JSON carries `truncated` and `total` (the items before truncation); a report that cannot be written is ERROR 2.
- **Outcomes:** PASS 0, FAIL 1, ERROR 2 (input unusable, bundle refused, output not written), INCOMPLETE 3 (`@import`, unsupported at-rules, unresolvable `color-mix()`, font shorthand through any variable but exactly one approved font-stack variable, more than 64 page-variable definitions in one declaration, more than 5,000 report items, receipt), INTERNAL 4.
