# check_page.py

A rendered page against its site's design system (plan 0.4 B.8; page scripts blocked by CSP, decision J1).

- **Inputs:** `<bundle> --page <relative path> --site <folder> [--out DIR] [--run-as USER] [--snapshot FILE | --kept FILE --kept-sha256 HEX] [--json FILE] [--no-git] [--receipt-sha256 HEX]`. `--json`, `--snapshot` and `--out` never inside the site design folder (ERROR 2). A bundle root that is a link is refused.
- **Order:** inputs, the vendored axe-core (SHA-256 pins; mismatch ERROR) and Playwright checked first → receipt (missing, invalid, stale or, where a repository is reachable, not equal to its committed blob: INCOMPLETE, nothing rendered; with no Git repository approval counts only with `--receipt-sha256`) → the 120 s deadline starts → the page's reference closure (page, linked sheets, `url()` tokens outside comments and strings, `@import`, images and `srcset`, `poster`, same-bundle frames, `srcdoc` documents to 8 levels, fonts; never scripts; nothing inside `<template>`), each file read once through the guard shared with `check_css.py`, relative to the bundle root opened once (a root replaced during the run is refused) → the closure's own A10 findings are reported at once → the same bytes staged into a new folder (the page's SHA-256 is the staged bytes') → a renderer child process (exact containment modes only; its job must name the parent's staging folder and list the staged inventory) → four renders (1280×800, 390×844 × light, dark; reduced motion, no contrast or transparency preference), each followed by fresh loads of the page in the 11 other reader-preference states, all within the one deadline.
- **Bundle paths:** one portable component grammar, on every platform, before anything is opened, logged or staged: a component that ends in a dot or a space, holds `:` (a Windows stream such as `::$DATA`, a drive), `\`, `<`, `>`, `"`, `|`, `?`, `*` or a control character, holds `~` followed by a digit (a short 8.3 alias such as `GIT~1`), or is a Windows device name with or without an extension (`CON`, `PRN`, `AUX`, `NUL`, `COM0`–`COM9`, `LPT0`–`LPT9`, superscript digits included) is outside the bundle (A10), never read. Then a VCS, `.env*`, `*.pem`, `*.key` name in any component, profile file names, bytes equal to a site design folder file, links, junctions, reparse points, hard links and devices are refused (ERROR); over 500 files or 20 MB: INCOMPLETE; a percent-decoded control character leaves the bundle (A10). Every SVG file of the closure is scanned for scripts and event handlers (the script rule).
- **The loopback server and the private renderer:** the renderer (`check_page.py --_render <job>`, a hidden entry) serves only the keys of the staged inventory its job lists: a request whose percent-decoded path is not byte-equal to a key (`.` or `..` segments, `//`, an encoded `/` or `\`, a case variant) is 404 and logged as refused; a listed file is sent only when its bytes match the inventory's SHA-256. Every response is logged with the exact staged key served and the SHA-256 of the bytes sent; A1 judges fonts by those, never by a second lookup of the requested path. Every response carries `Content-Security-Policy: script-src 'none'; object-src 'none'; base-uri 'none'; worker-src 'none'`. The hidden entry trusts its job, which only `check_page.py`'s parent writes, and gives no verdict; it writes only the staging folder's `out/result.json`.
- **Containment:** Linux: a new network namespace with only loopback up (as root, then `--run-as USER`; as another user, a user namespace too): `containment: os`. Elsewhere: a dead proxy for every host and every other loopback port (only the checker's origin bypasses it), routing (only that origin, `data:`, `blob:`; WebSockets closed): `containment: browser` (`SDS_FORCE_BROWSER_CONTAINMENT=1` forces it on Linux, for tests). A canary file outside the stage that nothing references must never be requested (A10 says only that); containment itself is proved by the tests, which first reach a listener and then see no request.
- **Page scripts (INCOMPLETE, named; the owner's decision of 2026-11-10):** every `<script>` (a `type="application/ld+json"` block included), inline `on*` handler, `javascript:` URL in any URL attribute (normalised as browsers do: tabs and newlines removed) and `<meta http-equiv="refresh">` in the page's closure, nested `srcdoc` documents and SVG files included; scripts are never staged and never run.
- **Evidence in one state:** the checker changes no document it checks: no attribute, element, stylesheet node or text node (an element's identity is its index in `querySelectorAll('*')`, kept in its scripts; CDP node ids come from the document tree read once; axe runs with `elementRef`; the overlap probe forces nothing on and also checks the boxes of elements with `pointer-events: none`). The viewport never changes size: the main frame is scrolled (instantly) to the offsets that bring every text run wholly into the viewport, up to 20,000 px and at most 40 offsets per render; each run's contrast, overlap and font evidence is taken at the first offset where it lies wholly inside the viewport, and a run that never does gives A6 INCOMPLETE "text not inside the checked viewport" (and A1 INCOMPLETE). Every frame's paints (the one list `PAINT_PROPS` of `pagejs.py`, read by every comparison: colours, visibility, display, offsets, margins, `transform`, `scale`, `rotate`, `translate`, `clip`, `zoom`, `content-visibility`, `box-shadow`, border colours, widths, styles and radii, outline colour, width, style and offset, background size, position, repeat, clip, origin, attachment and blend mode, padding, `width`, `height`, border image, `-webkit-box-reflect`, `accent-color`, `color-scheme`, text decoration line, style and thickness, mask size, position and repeat, overflow, `offset-path`, SVG stroke width and opacities; the same list for each `::before` and `::after` whose `content` is rendered) are read first, at every offset used and after all other evidence; any difference on any element of a frame gives every text run of that frame A6 INCOMPLETE ("the page's paint changed during checking"), a named axe violation excepted (it stays FAIL). Text in a child frame whose own document paints no opaque background beneath it (its root and every box beneath the text transparent) gives A6 INCOMPLETE ("the backdrop lies outside the frame"), whatever axe says in that frame.
- **Reader preferences:** the evidence page of each render is loaded with `prefers-reduced-motion: reduce`, `prefers-contrast: no-preference` and `prefers-reduced-transparency: no-preference`, with its colour scheme, all pinned by CDP `Emulation.setEmulatedMedia` before the load (the host's own settings never decide them). After the evidence, the page is loaded again, fresh (a new context with the same routing, proxy and request log; never a switch of the live page, where a transition could hold the old value), in each of the 11 other combinations of reduced motion (`reduce`, `no-preference`), contrast (`no-preference`, `more`, `less`) and reduced transparency (`no-preference`, `reduce`), and every checked frame's paints (the same `PAINT_PROPS`) and every element's border box (in page coordinates; every one of these loads, and the evidence page's first read, is at offset 0, so boxes compare directly; the comparisons while scrolling do not read boxes, since sticky and fixed boxes move) are read once, after fonts are ready, and compared with the evidence page's first read, frame by frame (a different frame list changes every frame). Any difference gives every text run of that frame A6 INCOMPLETE ("the page paints differently for readers with another preference: <states>"), a named axe violation excepted (it stays FAIL). A state not confirmed in its page by `matchMedia` (or fonts not ready there), an evidence page whose own state is not confirmed, or a state missing from the record gives every text run A6 INCOMPLETE ("the page was not checked for readers with another preference"). Only A6 reads these loads; the other assertions judge the evidence state. Not emulated: `forced-colors: active` (and `prefers-contrast: custom`, which goes with it), where the user agent replaces the page's colours.
- **Paints hit testing never sees (A6):** axe ignores `box-shadow` and outlines, the fallback composes neither, and `elementsFromPoint` never hits a shadow, an outline or a border image outside its box. Where each text run is evidenced, `UNSEEN` measures the border box (viewport coordinates of that scroll position) of every element with a box-shadow, an outline, a border image or a `blur()` or `drop-shadow()` filter, which of them has a running or pending animation or transition (`getAnimations()`, a delayed one included), and the run's own text rectangles. A run is INCOMPLETE ("a shadow paints under the text: <element>", "an outline is drawn over the text: <element>", "a border image paints under the text: <element>") when a painting layer reaches it: an inset shadow of the run's element or an ancestor, or of any element whose padding box meets a text rectangle; an outer shadow whose border box, moved by its offset and grown by its spread, then by 1.5 × its blur (Chromium blurs with a Gaussian of deviation blur / 2; Skia draws it to three deviations) and one pixel of antialiasing, meets a text rectangle that does not lie inside the element's own border box with its used corner radii (scaled down as CSS does; an outer shadow never paints there, so a card's own shadow does not touch the card's text; an inline element in line fragments, or unreadable radii, excludes nothing); an outline whose ring (outside the border box grown by `outline-offset`, `outline-width` wide; inside the box for a negative offset) meets one; a border image whose area (the border box grown by `border-image-outset`) meets one. A transparent layer, or one with no offset, blur or positive spread, paints nothing. **Solid bands are composed (U2):** an inset layer with no blur and a readable colour of the run's element or an ancestor is composed exactly into the fallback's backdrop instead: a solid layer with its alpha, above the backgrounds of the element that paints it and beneath those of its descendants (an inset shadow paints above its element's backgrounds and beneath its content), an element's layers in paint order (the first listed on top); layers of one element with the same offset and spread paint the same area and form one group. A part of the run may lie under any set of the groups, so the run passes only when its text meets the threshold over the plain backdrop and over every combination of the groups; it fails when one has a real point below the threshold ("… with the solid shadow band(s) of <element> composed (U2)", or "… without …" for the plain backdrop), and is INCOMPLETE otherwise, with more than 4 groups, a band painted inside a faded group, a painter with a running or pending animation (it may paint otherwise after the check), or text in a stacking layer with a negative `z-index` between the painter and the text (CSS paints such a layer beneath the band). Every other shadow layer that reaches the run (an outer one, a blurred one, one of a non-ancestor) stays INCOMPLETE. **Filters that paint beyond their input (U1):** a `blur(r)` filter reaches 3 × r beyond the border box of the element it filters (r is the Gaussian's standard deviation); a `drop-shadow(dx dy b)` adds that box moved by (dx, dy) and grown by 1.5 × b; the functions apply in order; one pixel is added. Only a run that meets that rectangle where it was evidenced is INCOMPLETE ("a filter of <element> (…) paints within reach of the text"). The border box bounds what the filter takes in only for an element with no child elements and no text, no rendered `::before` or `::after`, no box-shadow, outline or border image of its own, not SVG or replaced content (`img`, `video`, `canvas` and the like) and not a list item (its `::marker` may lie outside); a filter on an animated element gives every run INCOMPLETE ("is animated"). When the reach is not computed, every text run of the frame is INCOMPLETE, never PASS: a filter that cannot be read (an SVG filter `url()`, an unknown function, a length that is not `px`), a `blur()` or `drop-shadow()` filter on an element whose border box does not bound what it filters or that is (or whose ancestor is) transformed, zoomed or on a motion path, a `-webkit-box-reflect`, a box-shadow, outline, border image, filter or reflection of a rendered `::before` or `::after` (no box is measured for it), a box-shadow value that cannot be read (a missing colour, a length that is not `px`, a negative blur), a shadow, outline or border image of an element that is, or whose ancestor is, transformed (`transform`, `scale`, `rotate`, `translate`), zoomed or on a motion path, and an element whose box was not measured where the run was evidenced. An element with `display: none` on itself or an ancestor, `display: contents` or an effective opacity of 0 paints none of these; one with `visibility: hidden` paints no shadow, outline or border image of its own. Not detected: a `text-shadow` of another element reaching the run; a paint of a parent document over a child frame's text; a `::marker` of a list item drawn under another element's text (hit testing returns the list item and axe reads its background, not the marker's glyph); text in a stacking layer with a negative `z-index` painted beneath an ancestor's opaque background (the fallback composes the chain's backgrounds in tree order).
- **Filters on text (A6):** axe-core composes no CSS filter, so where axe passed a text run whose element or an ancestor has a `filter` or `backdrop-filter`, A6 is INCOMPLETE ("axe passed, but filter … on …: axe does not compose filters"; the CEO's decision of 2026-11-12). The fallback already gave INCOMPLETE for both.
- **A6's fallback over a gradient (the proved bound):** with stops interpolated in sRGB, each encoded channel is affine in the position on an interval between two opaque stops; each linearised channel is a convex, increasing function of its encoded channel, so the relative luminance is convex in the position. Its maximum on the interval is at an end; its minimum is found by ternary search (100 steps, narrowing the interval to (2/3)^100), and a margin of 1e-9 in luminance is subtracted (far above the search and rounding error). Against opaque text of luminance L: when L lies above the interval's maximum, the lowest ratio is exact at the lighter end; when the minimum found lies at or below L, a point of equal luminance exists (ratio 1); otherwise the bound is (min − margin + 0.05) / (L + 0.05). A translucent solid layer over an interval composites to an interval (an affine map), so it keeps the proof. PASS only when the bound over every interval and colour reaches the threshold; FAIL when a real point (the minimum found or an end) lies below it; INCOMPLETE otherwise. Not proved: translucent stops (premultiplied interpolation), a gradient above another, translucent text over a gradient: a sample below the threshold (17 per segment) still gives FAIL, else INCOMPLETE. SVG text composes `fill-opacity` with the element's opacity; a paint server `url(…)`, `context-fill`, `context-stroke` or a visible stroke of non-zero width gives INCOMPLETE.
- **Generated text:** text in `::before`/`::after` `content` gets A6 INCOMPLETE; its colour is judged by A2 and A5.
- **A12 in frames:** axe's top-document rules (`document-title`, `html-has-lang`, `aria-hidden-body`, `meta-viewport`, `meta-viewport-large`) run in the main frame only.
- **Not visible to the checker (INCOMPLETE, named):** frames other than same-bundle, `srcdoc` and `about:blank` ones (a `data:` frame); shadow DOM (open or closed); `::first-line` and `::first-letter` repaints (A6); fonts not ready within 5 s. `img`, `canvas` and `video` contents are listed as NOT_CHECKED.
- **Assertions:** A1 fonts in all four renders (CDP `CSS.getPlatformFontsForNode` at the offset where the run is inside, empty data INCOMPLETE; approved PostScript names whose approved file was served; every served response that is a font by its first bytes checked by the SHA-256 the server logged for the staged key it sent, a response not tied to staged bytes INCOMPLETE; `@font-face` sources only bundle files, never `data:`, `blob:`, `local()` or remote; weights; style; coverage), A2 palette by role (every non-empty paint: gradient stops of any spelling, SVG paint-server stops, a `url(…)` paint's fallback colour, a `url(…)` with no fallback naming no gradient of the document INCOMPLETE; `color(srgb …)` and `color(srgb-linear …)` converted exactly, any other space a floor INCOMPLETE; reserved tokens floor), A3 headings, A4 limited fills (layout area), A5 forbidden text colours (SVG fill included), A6 contrast (above; every axe violation a FAIL, unresolved ones named by axe's selector; text runs by their text rectangles; a differing `-webkit-text-fill-color` or SVG text goes to the fallback), A7 measure (layout content width, unrounded), A8 capitals (every render), A9 schemes (paints, visibility, display, opacity), A10 self-containment, A11 primary buttons (both desktop renders; by `buttons.selectors` and by the paint signature `buttons.paint`, or by selectors alone with `paint: selectors-only`), A12 accessibility (policy tags; H3 rules blocking; `accessibility.default` the tier of every other unlisted rule, advisory when absent; both schemes; every checked frame needs a result, and every rule axe-core has for the selected tags must appear in it, else INCOMPLETE naming the rule), A13 structure (`--snapshot` prints its SHA-256; `--kept FILE` counts only with `--kept-sha256 HEX`, that value; every listed element — `input`, `button`, `select`, `textarea`, `output`, `fieldset`, `object`, `<input type="image">` included — credited once to its owner `element.form`, an unowned one listed as such; the snapshot's schema, full page hash and complete coverage required; the desktop light render compared, named in the item). Execution summaries are INFO; findings keep their render.
- **Outputs:** report (text, `--json`, written before the summary; at most 5,000 items, the truncation item included), the snapshot, and in `--out` the viewport-size captures taken at the scroll offsets used (`<render>.png` at the top, `<render>-at-NNNNN.png` below; a capture's pixel area is the viewport's, bounded before capture; dark ones kept only for dark findings). Every output is written to a new file in its folder and renamed into place; an existing name that is a link, a junction, a hard link or not a regular file is refused and nothing is written. The captures and the renderer's result share one 60 MB artefact budget (a capture's PNG is held in memory once before it is written); a result over the room left is written bounded: its A10 evidence (requests, aborted requests, web sockets, the access log; each list cut to 1,000 entries, with its count), the rest reported INCOMPLETE. An output that cannot be written is ERROR 2.
- **Outcomes:** PASS 0, FAIL 1, ERROR 2 (bundle refused, Playwright or Chromium unusable, axe changed, output not written or refused), INCOMPLETE 3 (receipt, isolation, budgets, no text, undecided contrast, paint changed while checking, a frame that paints differently for readers with another preference or a preference state not checked, text not inside the checked viewport, a backdrop outside the frame, a shadow, outline or border image reaching the text, a paint whose reach is not computed, a filter on text axe passed), INTERNAL 4.
